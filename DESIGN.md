## 1. Описание сайта

**Тип:** официальный сайт общего образовательного учреждения (гимназии).

**Миссия / позиционирование:** «Открываем дорогу к знаниям и будущему» — современный, открытый информационный портал гимназии: сильное образование, внимательное отношение к каждому ученику, активная школьная жизнь (проекты, Движение Первых, спорт, летопись).

**Целевая аудитория:**
- родители учеников и потенциальных абитуриентов 1 класса;
- ученики гимназии;
- педагоги и сотрудники;
- городские структуры, проверяющие органы, партнёры.

**Ключевые задачи сайта:**
1. Быстро дать ответ на частые вопросы родителей: приём и условия, вакантные места, режим работы, питание, профориентация.
2. Держать в курсе школьной жизни: новости, «Наши приоритеты», проекты, летопись.
3. Обеспечить доступ к госcервисам: «Госуслуги Моя школа», электронные сервисы bus.gov.ru.
4. Обеспечить обратную связь: отзывы и предложения директору, горячие линии, телефон доверия.
5. Показать лицо школы: директор, коллектив, видео о гимназии, соцсети.

## 2. Дизайн-система (стиль сайта)

Все значения вынесены в CSS-переменные (`:root`) в начале `<style>` в `index_static.html`.

### 2.1 Палитра

| Токен | Значение | Назначение |
|-------|----------|------------|
| `--ink` | `#374957` | Основной текст ( slate ), тёмные поверхности |
| `--ink-deep` | `#17252f` | Фон подвала, градиенты затемнения |
| `--muted` | `#6b7a88` | Вторичный текст, даты, описания |
| `--accent` | `#4d4cff` | Фирменный синий: кнопки, ссылки, hover, выделения |
| `--accent-dark` | `#3a38d6` | Hover активной кнопки |
| `--accent-soft` | `rgba(77,76,255,.08)` | Подложка тегов/бейджей |
| `--gold` | `#ffd700` | Акцент «Движения Первых», hover-ссылки в подвале |
| `--danger` / `--info` | `#d52c27` / `#227cc1` | Фирменные цвета логотипа «госуслуги» |
| `--bg` / `--bg-soft` / `--bg-softer` | `#fff` / `#f1f5f9` / `#e8eef4` | Фон страницы / панелей |
| `--border` | `#e2e8f0` | Обводки карточек, разделиели |

Правило: синий `--accent` — единственный «действующий» цвет (кнопки, ссылки, активные состояния). Красный/синий госуслуг и золотой используются только в соответствующих брендированных блоках.

### 2.2 Типографика

- Шрифт: **Inter** (подключён локально из `src/assets/fonts`, fallback system-ui/Roboto), для декоративных вставок — Roboto.
- Scale: `13 / 15 / 16 / 18 / 22 / 26 / 32px`, заголовок героя — fluid `clamp(28px, 4vw, 44px)`.
- Заголовки: weight 700–800, лёгкий отрицательный трекинг (`-.01…-.02em`).
- Бейджи/теги: 13px, uppercase, трекинг `.08em`.
- Базовая высота строки — 1.5; длинные тексты ограничены `max-width: 52ch`.

### 2.3 Форма, сетка, тени

- Контейнер: `max-width: 1240px`, боковые отступы 20px.
- Радиусы: крупные панели/баннеры — `24px`, карточка новости — `12px`, кнопки — `10px`, чипы — `999px`.
- Секции: вертикальный ритм `32px` (на мобильных `24px`), герой/директор — увеличенные отступы.
- Тени: три уровня soft-теней на основе `rgba(55,73,87,…)` — sm/md/lg; у основной кнопки — цветная тень `rgba(77,76,255,.28)`.

### 2.4 Компоненты

- **Кнопка** (`.btn`): синяя, белый текст, radius 10px, цветная тень; hover — тон темнее + подъём на 2px. Вторичная (`.btn--ghost`) — прозрачная с обводкой; hover — синяя обводка и текст.
- **Карточки**: белые, border `--border`, radius 12–16px; hover — подъём, усиление тени, акцентная рамка/цвет заголовка. Изображения внутри карточек при hover слегка увеличиваются (zoom 1.04–1.05, overflow hidden).
- **Панели** (`.panel`): светло-серый диагональный градиент, radius 24px, внутренник 40px.
- **Быстрые ссылки**: серые плитки min-height 124px в auto-fill сетке ≥240px; hover — белая плитка + синяя рамка.
- **Навигация**: sticky, полупрозрачный фон + `backdrop-filter: blur(8px)`; underline-индикатор ссылки выезжает слева при hover.
- **Баннеры**: фото с градиентной подложкой снизу и белой подписью.
- **Видеоблок**: затемняющий градиент поверх превью, круглая кнопка play, жёлтая звезда + CTA.

### 2.5 Анимации и взаимодействия

- Единый transition-стандарт: `0.2s ease` (цвета/тени), `0.4s` (zoom изображений).
- Появление секций при прокрутке: IntersectionObserver добавляет `.visible` (fade + slide-up 18px). Полностью отключается при `prefers-reduced-motion: reduce`.
- `scroll-behavior: smooth` для якорей.

### 2.6 Адаптивность

- **≥1025px**: двухколоночный герой (текст + фото 600px), полная шапка с контактами.
- **≤1024px**: герой в одну колонку, скрываются контакты шапки, уменьшаются отступы секций.
- **≤640px**: компактные карточки быстрых ссылок, маленький портрет директора (160px), CTA видео уходит под блок, нижняя строка подвала — по центру. Меню остаётся горизонтально скроллящимся с тонким скроллбаром.

### 2.7 Доступность и SEO

- Семантика: `header/nav/main/section/footer`, один `h1` (ФИО директора как лицо учреждения), `time datetime`, `blockquote`.
- Skip-link «Перейти к содержимому», видимые `:focus-visible`-обводки, `aria-label` на иконочных ссылках и кнопке play, `alt` у содержательных изображений.
- Метаданные: развёрнутый `description`, `keywords`, Open Graph (`og:*`), `theme-color`, favicon, `lang="ru"`.
- Изображения — `loading="lazy"` (кроме hero/logo), шрифты — `font-display: swap`.

## 3. Как менять стиль

Все базовые константы правятся в одном месте — блоке `:root` в `index_static.html`:
сменили `--accent` — обновились кнопки, ссылки, ховеры и тени; изменили `--radius` — вся система скруглений. Дальнейшая разработка (перенос в React-компоненты `src/`) должна использовать те же токены, чтобы статическая и SPA-версии выглядели идентично.
